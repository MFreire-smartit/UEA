# Reserva de Asiento en Sala de Cine

**Estudiante:** Freire Shiguango Michael Daniel

## Objetivo del programa

Simular la reserva de un asiento en una sala de cine de 3 filas por 4
columnas. El programa guarda la sala en una matriz (lista de listas),
pide una fila y una columna, reserva ese asiento y muestra la sala
completa con bucles anidados.

- `0` = asiento libre
- `1` = asiento reservado

## Cómo ejecutarlo

1. Tener Python 3 instalado.
2. Ejecutar en la terminal:

   ```
   python reserva_cine.py
   ```

3. Ingresar la fila (0 a 2) y la columna (0 a 3) del asiento a reservar.
4. El programa muestra la matriz de la sala con el asiento reservado.
